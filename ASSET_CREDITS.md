# ASSET_CREDITS

All content in this repository is either generated in-repo or comes from Unity packages under their licences.
No content was downloaded from third-party asset sites (they were not reachable from the cloud session;
see `DECISIONS.md`). Nothing here reproduces real-world firearm designs or recorded firearm audio.

| Asset group | Source | Licence / notes |
|---|---|---|
| Weapon meshes `Assets/Art/Weapons/*.obj` | Generated by `Tools/AssetGen/gen_weapons.py` (original parametric models) | Project's own; redistributable |
| PBR textures, target faces, decals, FX sprites, signs `Assets/Art/**` | Generated by `Tools/AssetGen/gen_textures.py` (numpy + Pillow; DejaVu Sans font for sign text) | Project's own; DejaVu fonts are under the DejaVu licence (free, redistributable) and only rasterised into PNGs |
| Audio `Assets/Audio/**` | Synthesised by `Tools/AssetGen/gen_audio.py` (noise bursts, resonators, comb reverb) | Project's own; redistributable |
| XR rig, controller models, teleport reticles, vignette, input actions `Assets/Samples/XR Interaction Toolkit/3.3.2/Starter Assets` | Unity XR Interaction Toolkit 3.3.2 sample (committed as Package Manager imports it, demo scene removed) | Unity Companion License (use within Unity projects) |
| Environment meshes `Assets/Generated/Meshes` | Built at setup time by `Assets/Editor/Util/EditorMeshUtil.cs` | Project's own |
| Fonts for UI | TextMeshPro default (LiberationSans SDF from TMP Essential Resources) or fallback from Unity's built-in font | Unity / SIL Open Font License |

Honest deviation from the brief: the three weapons are stylised procedural models, not scanned or
hand-sculpted assets. They are clearly a pistol, a rifle and an SMG with animated slide/charging handle,
trigger and magazine, but a local session may swap in higher-fidelity models by replacing the OBJ files
listed in `Assets/Art/Weapons/weapons_layout.json` (keep part names and pivots).
