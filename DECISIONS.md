# DECISIONS

| Decision | Choice | Why / alternatives |
|---|---|---|
| Unity version | 6.3 LTS, pinned `6000.3.27f1` in `ProjectVersion.txt` | 6.0 LTS support ends Oct 2026; 6.3 is the current LTS. Any 6000.3.x works (Hub offers the installed one). |
| Render pipeline | URP 17.3, Forward, 4x MSAA, no HDR, per-vertex additional lights | Standard mobile-VR configuration; Quest 2 fill-rate bound. |
| XR stack | OpenXR 1.16.1 + XR Interaction Toolkit 3.3.2 (+ Meta Quest Support feature, Oculus Touch profile) | Unity's recommended path for Quest; Oculus XR plugin is deprecated. No Meta XR SDK to avoid conflicts. |
| Rig | XRI **Starter Assets** sample committed verbatim (`Assets/Samples/.../Starter Assets`) | Correct Quest bindings, teleport, snap turn, ray/direct/poke interactors maintained by Unity; identical to what Package Manager imports. Demo scene removed. |
| Scenes / prefabs | Generated by idempotent editor code on first open (`VR Range > Setup`) | No Unity available in the cloud; hand-authored YAML would be fragile. Generated assets are plain Unity assets afterwards. |
| Weapons art | Parametric OBJ parts from `Tools/AssetGen/gen_weapons.py` (chamfered boxes + cylinders), PBR materials | Asset sites were unreachable from the cloud (network policy). Original, redistributable, Quest-friendly (≤ 1.1k tris each). Replaceable by swapping the OBJ files. |
| Textures / audio | Procedurally generated (numpy/Pillow, numpy synthesis) | Same reason; fully redistributable, documented in `ASSET_CREDITS.md`. |
| Projectiles | Manual integration + swept raycast, pooled | Deterministic, no tunnelling, no physics garbage; visible drop/time of flight at range. |
| Input extras | Runtime-created Input System actions (A/X reload, B/Y fire mode) | Avoids editing the XRI action asset; XRI *Select/Activate* handle grab/fire. |
| Recoil | Weapon model only (`WeaponAnimator`) + haptics | Requirement: never move the camera. |
| Lighting | Baked GI + subtractive mixed lights, emissive panels, light probes, reflection probe | Bake locally (`VR Range > Build > Bake Lighting`); before baking the mixed lights keep the scene lit. |
| Cloud validation | Roslyn + reference assemblies built from UnityCsReference 6000.3 and package sources (`Tools/CloudCompileCheck`) | Catches API/signature errors without Unity. Two editor files (URP + OpenXR setup) are verified by source inspection only. |
| Cloud real-editor run | GameCI `unityci/editor:ubuntu-6000.3.27f1-android-3.2.2` in Docker inside the cloud VM, Unity command-line activation with the owner's Student seat (credentials via environment variables, never logged; seat returned with `-returnlicense`) | Only official headless activation route left for Personal/Student seats; produced real compile/test/APK evidence (see `TEST_RESULTS.md`). |
| Generated assets committed | `Assets/Generated`, `Assets/Scenes`, `Assets/Settings`, `Assets/XR`, `Assets/XRI`, `ProjectSettings`, `packages-lock.json` and all `.meta` files from the cloud editor run are committed | Stable GUIDs and a project that opens ready to build; the generators remain for rebuilds. |
| Gradle repositories | `Assets/Plugins/Android/settingsTemplate.gradle` puts Google Maven and Google's Maven Central mirror before Maven Central | Maven Central rate-limited the cloud egress IP (HTTP 429), which Gradle treats as fatal. Harmless locally. |
| TMP essentials | Committed under `Assets/TextMesh Pro` (Unity Companion License) | Batch-mode import of the .unitypackage does not complete; committing avoids the manual import step. |
| Weapon weight (V2) | Custom XRI grab transformer (`WeaponHandlingTransformer`) replacing XRI's general transformer: first-order lag with clamps, sag, Perlin sway, two-point aim with support-hand influence, blend timers, recoil spring | Weight cannot be felt on Quest 2; lag/sag/sway/recoil on the target pose give the sensation while the tracked controllers and camera are never modified. Clamps keep aiming possible. |
| Hands (V2) | XR Hands sample rig driven procedurally (`HandPresence`): curl axes auto-calibrated from the rest pose, poses as ScriptableObjects, hands snap to weapon grip anchors | No hand-tracking package needed; Touch controllers give grip/trigger only, so pose presets + trigger finger are the honest representation. Rig works for both hands without hand-authored axis tables. |
| Textures (V2) | ambientCG CC0 1K sets instead of procedural noise for the environment and weapon base materials | Real photoscanned PBR for a premium look; CC0 keeps redistribution simple; 1K + ASTC fits Quest 2. |
| Git | No LFS (largest asset 2.6 MB), binaries committed directly | Total assets ≈ 12 MB; LFS quota not needed. |
